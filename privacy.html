Kebijakan Privasi Aplikasi ILU (I Listen to You)

Terakhir Diperbarui: 29 Agustus 2026

Aplikasi ILU (I Listen to You) dikembangkan oleh Rahma dari SMA Islamic International School PSM Magetan. Kebijakan privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi pribadi pengguna saat menggunakan aplikasi mobile ILU.

1. Informasi yang Kami Kumpulkan

Untuk mendukung fungsionalitas pendamping emosional dan pemantauan klinis, aplikasi kami mengumpulkan beberapa data berikut:

  • Nama Panggilan: Disimpan secara lokal di perangkat Anda (menggunakan SharedPreferences) untuk kebutuhan personalisasi sapaan oleh AI pendamping.
  • Riwayat Percakapan (Chat Logs): Isi obrolan Anda dengan AI disimpan di database lokal perangkat Anda dan disinkronkan ke Firebase Firestore.
  • Data Terapi Gratitude: Catatan tiga hal baik harian yang Anda tuliskan disimpan secara terstruktur di database Firebase Firestore.
  • Log Deteksi Krisis: Apabila sistem mendeteksi kata kunci sensitif terkait kondisi krisis psikologis (self-harm), sistem akan mencatat waktu kejadian dan kata kunci pemicu tersebut ke dalam basis data Firebase Firestore.

2. Penggunaan Informasi

Data yang dikumpulkan digunakan semata-mata untuk tujuan berikut:

  • Menyediakan layanan chat interaktif berbasis kecerdasan buatan (menggunakan model GPT-5.6 Luna melalui API OpenRouter).
  • Memfasilitasi terapi psikologi positif (Gratitude Therapy).
  • Memberikan akses kepada pihak rumah sakit berwenang untuk memantau kondisi perkembangan emosional pengguna secara real-time guna penanganan medis lebih lanjut jika terjadi kondisi krisis darurat.

3. Keamanan Data

Kami sangat berkomitmen untuk menjaga keamanan data pribadi Anda. Data obrolan dan log krisis Anda disimpan di server cloud Firebase Firestore yang dilindungi enkripsi standar industri Google. Data tersebut tidak akan dibagikan kepada pihak ketiga di luar tim medis rumah sakit pemantau dan tim pengembang aplikasi.

4. Penghapusan Data

Pengguna memiliki hak penuh untuk meminta penghapusan seluruh data percakapan mereka dari server database kami. Penghapusan data dapat diajukan melalui tim pengembang atau akan dilakukan secara otomatis oleh Administrator Developer jika masa program pemantauan selesai.
